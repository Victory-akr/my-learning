# 资料查询助手 v0.1

职业规划展示用的初步原型。先从自己的公开学习资料开始，实现“输入问题 → 找到原文 → 核对来源”。后续可以导入校园公开文档，逐步发展为校园资料问答助手。

## 运行

直接用现代浏览器打开 `index.html` 即可，无需安装、账号、密钥或网络服务。所有 JS 与样式均为本地文件。查看远端原文链接需要网络。

也可在本目录运行 `python -m http.server 8765`，浏览器访问 `http://localhost:8765`。

## 演示步骤

1. 点“C语言练习怎么编译？”：显示内置学习资料中的原文及来源。
2. 点“make test”：找到测试命令所在段落。
3. 点“资料之外的问题”：显示未找到依据。
4. 导入自己的 TXT 或 Markdown 文件，输入其中的关键词查询；恢复内置资料会清除导入内容。

## 当前完成范围

- 按 Markdown 标题分块，中文双字词与英文关键词匹配。
- 展示最多3个相关片段、文件名、行号和原文件链接。
- 导入本地 TXT / MD，只在当前页面内存中处理。
- 支持无结果提示、空输入检查和文件大小检查。

尚未实现大模型生成回答、向量检索、OCR、PDF解析或正式校园规章知识库。匹配到关键词不代表已经回答问题，结果必须人工核对。当前版本没有对外准确率承诺。

## 资料与开发说明

内置数据为本人 `Victory-akr/ds-cpp` 公开 README 的快照，保留原文和来源地址；不代表完成了该仓库规划中的所有数据结构。未引入第三方项目源码。本原型在 AI 辅助下搭建，后续需继续阅读、理解和修改实现。

## 检查

`node --test search.test.js`：检查中文查询、命令查询、来源与行号、空输入、资料之外的问题和本地文档查询。

本作品独立存放于 my-learning 的 demos/doc-finder，未使用微信小程序代码或资源。
